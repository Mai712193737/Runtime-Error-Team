​📌 Rules of Engagement (How We Commit)
​To avoid git conflicts and maintain pure code efficiency, every member must follow these rules:
​Branching: Never commit directly to main. Create your own branch (e.g., mai-terror, omar-terror, mohamed-terror).
​Commit Messages: Use standard clean conventions:
​feat(codeforces): add 158A - Next Round solution
​fix(leetcode): optimize 234A from O(N^2) to O(N)
​Code Reviews: No Pull Request is merged into main without at least one approval from another member to ensure the Time & Space Complexity is optimal.
